🍜 中餐家常菜谱 · Chinese Home Recipes

licenseMIT
recipes12
language中/EN
3D engineThree.js

An immersive, bilingual interactive cookbook for Chinese home cooking — built entirely with vanilla HTML, CSS, and JavaScript. No frameworks, no build step. Open the file and cook.

✨ Features

🌀 3D Spin-Wheel Navigator

Browse 10 recipes on an interactive Three.js 3D wheel. Click a dish to open its full recipe panel.

📖 Flip-Book Edition

Cinematic page-flip animation with watercolour SVG illustrations on a hand-painted porcelain plate.

🧊 Fridge Finder

Tell the app what's in your fridge and it matches recipes with ingredient overlap scores.

🌐 Bilingual

Full 中文 / English toggle — recipes, instructions, UI labels, and tips all switch instantly.

📁 Project Structure

chinese-recipes/
├── index.html          # 3D spin-wheel app (Three.js + OrbitControls)
├── scene.html          # Early 3D scene prototype
├── wheel_test.html     # Spin-wheel animation prototype
├── test_wheel2.html    # Wheel refinement iteration
└── *.png               # Design reference & render previews

chinese-cookbook.html   # Standalone flip-book edition (12 recipes)

🚀 Quick Start

No install required. Just open either file in a browser:

# Flip-book (12 recipes, offline-safe)
open chinese-cookbook.html

# 3D wheel app (requires internet for Three.js CDN)
open chinese-recipes/index.html
